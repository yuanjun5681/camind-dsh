# CAM 加工最小工作流程建议

本文根据 `/Volumes/UWorks/Projects/CAM/docs` 中的四份 Markdown 整理，说明从接件到零件交付需要做哪些事、谁负责、何时可以继续。本文是流程建议，不是生产操作规程，也不表示现有产品已实现全部环节。

减少重复录入、非必要工序、装夹和换刀，可以缩短准备与加工时间。必要的校验、交接和现场检验仍须保留。

CAM 软件交出经校验的工艺包后，软件任务可以结束；零件还要经过现场加工和检验。两者应分别记录完成状态，不能用“NC 已生成”表示“零件已合格”。

## 1. 企业准备

| 项目 | 内容 |
| --- | --- |
| 输入 | 企业加工范围、设备台账、实际刀具与工装、能力实测记录、工艺习惯和验收要求 |
| 处理 | 按启用领域整理配置，检查必填项、字段冲突和能力依据 |
| 输出 | 经确认的企业配置、配置版本及缺项清单 |
| 责任人 | 企业技术负责人组织确认；设备、工艺和质检人员提供各自资料；系统辅助校验 |
| 继续条件 | 已启用领域的必要配置齐全，影响加工的冲突已解决；缺项不以经验值代填 |

企业配置建立一次，设备或工艺能力变化时更新。每个零件复用这份配置，不再重新询问刀库、机床和加工习惯。

| 配置内容 | 需要明确的事项 |
| --- | --- |
| 加工范围 | 一般零件、注塑模、压铸模及实际具备的特种加工能力 |
| 设备池 | 本厂与外协设备的归属、可用性、系统、行程、承重及加工能力 |
| 刀具与工装 | 实际可用的刀具、刃长、悬伸、夹持范围及接口 |
| 工艺能力 | 稳定达到的精度、粗糙度、硬加工能力；EDM/WEDM 的实测边界 |
| 工艺习惯 | 来料、通孔、辅助实体、放电留量及穿丝孔处理方式 |
| 验收口径 | 检验项目、量具、抽检责任及温度折算要求 |

按启用领域填写相关参数。普通铣削企业不必填写整套电极参数；外协设备则并入同一设备池，按相同格式登记能力。

能力值应取企业实际稳定达到的结果。机床铭牌、文献极限和“可以买到”的刀具不能直接当成生产能力。必要参数缺失时，停止依赖该参数的规划，列出缺项。

配置每次修改保留版本。任务放行时冻结所用配置，后续更新不自动改变已开工任务。

依据：精简版 §1.5～1.7，详细版 §0.5。

## 2. 一件零件怎么走

每个步骤按输入、处理、输出、责任人和继续条件说明。下一步接收上一步的书面输出；必要材料缺失或数据矛盾时，退回补齐。责任分工是建议，企业应指定实际承担人。

```text
接件，补齐加工要求
    ↓
审图、读件，确认几何与检验要求
    ↓
定材料、基准、装夹和工艺路线
    ↑ 不满足加工能力时，调整设备、工艺或装夹后重新校验
    ↓
工艺负责人放行，冻结方案
    ↓
在工作副本上准备模型、编程和后处理
    ↓
校验刀路、NC和交接材料，放行工艺包
    ↓
现场按工艺节点加工，首件检验合格后继续
    ↓
终检、交付与归档
```

### 2.1 接件与要求确认

| 项目 | 内容 |
| --- | --- |
| 输入 | 订单、3D 模型、已有的 2D 图纸与技术要求、企业配置 |
| 处理 | 登记项目和版本，人工确认件别，录入材料、来料、精度及特殊要求 |
| 输出 | 项目输入记录、原始图纸与模型清单、待补信息清单 |
| 责任人 | 项目／受理人员录入，工艺员协助确认加工要求 |
| 继续条件 | 件别和项目必填信息明确，输入文件可用；未确认事项列明，不自动猜测 |

受理人员登记项目号、图号、版本，收集 3D 模型、已有的 2D 图纸和技术要求。同时录入：

- 件别、技术领域及零件功能，由人工确认；
- 材料牌号、当前状态、来料形式和毛坯尺寸；
- 公差、粗糙度、批量及交期；
- 热处理要求，以及需要热处理时的最终硬度；
- 攻丝、沉窝、纹理、刻字、配作关系等特殊要求。

这些信息只录一次，后续工序、程序和检验材料引用同一份记录。系统发现件别与几何或功能描述矛盾时，提示复核，不自行改判。

本阶段交出项目输入记录。缺少影响工艺设计的信息，先补齐再排工序。

### 2.2 审图与读件

| 项目 | 内容 |
| --- | --- |
| 输入 | 项目输入记录、图纸与模型、企业加工和检验能力 |
| 处理 | 核对图纸与实际几何，确认材料和来料状态，检查加工难点并确定检验方法 |
| 输出 | 审图记录、零件事实清单、材料与来料状态确认、检验要求、待确认项 |
| 责任人 | 工艺员主责；系统与 NX 提供测量、核对和显示辅助；检验员确认检验方法 |
| 继续条件 | 影响工艺设计的尺寸、要求和材料状态已有依据；不足以加工的图纸退回补充 |

工艺员核对图纸要求与实际几何，确认模型版本、单位、实体和加工范围。对孔、型腔、薄壁、深槽及功能面，分别记录已测事实、人工声明和待核实项。

审图时就确定重要公差的检验方法与量具。尺寸或要求不足以支持加工的，退回补图或补说明。

客户端负责显示与选面。精确尺寸、干涉和加工几何判断由 NX 完成；选中面须能对应回真实几何。显示网格不能替代精确测量。

本阶段交出零件事实清单、待确认项和检验要求。

### 2.3 排出可行的工艺路线

| 项目 | 内容 |
| --- | --- |
| 输入 | 审图记录、零件事实、材料与来料状态、检验要求、企业配置及适用规则 |
| 处理 | 粗排工序，判定加工方法和热处理节点，确定基准、装夹、设备与刀具，再回头细化 |
| 输出 | 工艺路线、结构化工序表、刀具与工装清单、检验卡草案、分支判定记录；需要时附电极或线割设计材料 |
| 责任人 | 工艺员主责，CAM 编程员参与；系统生成建议和校验结果 |
| 继续条件 | 工序、加工对象和依赖完整，所选能力可满足要求；缺值或设备池内无解时停止，不能靠拆工序绕过精度约束 |

先粗排，再结合材料状态、基准和加工能力细化。需要热处理或多次装夹的零件，往往要回头调整顺序，不能把排工序当成一次完成的动作。

每条路线需要回答以下问题：

| 问题 | 工艺设计中要给出的答案 |
| --- | --- |
| 用什么方法加工？ | 铣削、钻镗铰、磨削、EDM、WEDM或其他有依据的工艺 |
| 热处理何时做？ | 按图纸、材料依据和后续加工要求安排节点 |
| 怎样固定工件？ | 定位基准、工装、支承、压紧方式与位置 |
| 是否需要刻字？ | 按明确要求安排 |
| 分几次装夹？ | 在可达性、精度和热处理约束下减少装夹 |
| 怎样检验？ | 检验项目、量具，以及探伤、气密等专项要求 |

可以优先考虑铣削，减少不必要的电极拆分；有位置关系、必须同次装夹的要素应一起完成。在工艺依赖允许的范围内集中用刀。二次开粗、半精和清根只在残料或质量要求确实需要时增加。

“先面后孔”是参考顺序。没有五轴，也不能直接拆开必须同次装夹的要素；拆分后仍要证明精度能够满足要求。

能力不足时，依次检查：

1. 能否换用设备池中的其他设备，包括外协设备；
2. 能否改用其他工艺；
3. 能否拆分工序，并重新校验基准、装夹和精度；
4. 都不满足时，停止并说明缺少什么能力。

参数未填不属于能力不足。应直接报缺项，不能靠切换工艺绕过。

本阶段交出结构化工序表。每道工序记录工序号与类型、加工对象、基准和装夹、设备、刀具或电极、参数、余量和目标尺寸、检验项、前后依赖、执行方，以及是否生成程序。

依据：精简版 §1.6、§2.1、第 3～5 章，详细版 §1.5.3、§5.1。

### 2.4 工艺放行

| 项目 | 内容 |
| --- | --- |
| 输入 | 工艺路线及工序表、装夹与刀具方案、检验卡草案、分支判定记录及未决项 |
| 处理 | 审核工艺归属、能力、基准与装夹，确认特殊加工要求，冻结所用版本 |
| 输出 | 已放行的工序表与配套方案、输入／规则／配置版本记录、放行记录；不通过时给出退回原因 |
| 责任人 | 工艺负责人签发，工艺员和编程员处理退回项 |
| 继续条件 | 影响执行的缺值和冲突已解决，方案明确放行；后续变更须重新校验受影响工序 |

工艺负责人检查加工对象、材料与工艺归属，确认基准、装夹和热处理节点。设备、刀具及工装必须真实可用，特殊加工声明须齐全。

影响执行的缺值或规则冲突未解决时，不放行。

通过后冻结工序表、输入版本和所用规则、配置版本。后续变更留记录，并重新校验受影响的工序。

### 2.5 在工作副本上编程

| 项目 | 内容 |
| --- | --- |
| 输入 | 已放行方案、源模型、毛坯与夹具定义、刀具清单、机床与后处理配置 |
| 处理 | 复制工作副本，建立工位与坐标，准备辅助几何，绑定区域和参数，生成刀路并后处理 |
| 输出 | 加工副本、刀路、各工序 NC、辅助几何清单、编程异常记录 |
| 责任人 | CAM 编程员主责；系统调用 NX 执行建模、刀路生成和后处理 |
| 继续条件 | 原件未被覆盖，应生成的工序有可核对结果；做不了或方案发生变化时退回工艺设计 |

保留客户原件，复制工作副本。建立工位、坐标系、毛坯和夹具，再按已确认路线准备加工几何。

NC 加工区域正常参与加工；交给 WEDM 的区域按确认过的策略屏蔽；EDM 区域按规定留量。辅助实体是 CAM 模型中的虚拟几何，不是给实物补料。它须参与规定的过切检查，切削范围则排除补体。

绑定刀具、区域和参数后生成刀路，使用实际机床系统对应的后处理器输出 NC。

编程中发现某道工序做不了，应退回工艺设计调整，不临时改变加工归属。

本阶段交出加工副本、刀路、NC及辅助几何清单。

### 2.6 校验并交出工艺包

| 项目 | 内容 |
| --- | --- |
| 输入 | 冻结方案、加工副本、刀路、NC及辅助几何清单、检验和交接材料 |
| 处理 | 检查覆盖、过切、碰撞、残料、参数与坐标，逐项核对工序和文件，检查工艺包完备性 |
| 输出 | 校验报告、工艺包及程序放行记录；不通过时交出问题报告和未决项清单 |
| 责任人 | CAM 编程员组织校验，系统提供检查结果，由企业指定的程序放行责任人确认 |
| 继续条件 | 必要检查通过，适用交付材料齐全，工艺包明确放行；有执行相关未决项时不得标为可生产 |

程序放行前至少核对：

- 应加工工序是否都有结果，有无空刀路或未决失败；
- 刀路覆盖、过切、碰撞、残料和余量；
- 刀具与悬伸、转速、进给是否符合设备及工艺限制；
- 工位坐标、翻面后的基准关系；
- 工序与 NC 是否对应，程序文件是否实际存在；
- 特种加工交接要求是否完整，参数是否有来源。

有未决项时可以交出问题报告，但不能把工艺包标为可生产。通过校验后，由指定责任人放行程序与工艺包。

### 2.7 现场加工与首件检验

| 项目 | 内容 |
| --- | --- |
| 输入 | 已放行工艺包、实际来料、设备和工装、电极等适用实物、检验卡与交接要求 |
| 处理 | 按工艺节点分段执行，节点后复查材料与基准，完成首件检验、过程检验和外协验收 |
| 输出 | 加工后的零件、首件放行记录、过程检验及外协验收记录、异常与变更记录 |
| 责任人 | 操机工及相应热处理、电极、放电、线割人员执行；检验员检验，指定责任人确认首件放行 |
| 继续条件 | 首件合格并放行后才继续批量加工；工艺节点复查或交接验收不通过时停止相关后续工序 |

现场按冻结路线执行。热处理、时效等节点插在各自的位置，不能先做完全部 CNC 再统一处理。

经过这些节点后，复查材料状态、变形和基准；必要时重新判定后续工艺。首件按检验卡确认，合格后才继续批量加工与巡检。软件仿真不能替代首件检验。

外协和特种加工按书面要求交接，返回后验收。本阶段记录首件结果、过程检验及外协验收。

### 2.8 终检与交付

| 项目 | 内容 |
| --- | --- |
| 输入 | 加工后的零件、图纸与检验卡、过程及外协验收记录、最终工艺包和变更记录 |
| 处理 | 完成终检和专项检验，核对实际交付物，记录不合格处置并归档 |
| 输出 | 终检报告、零件合格交付结论、实际交付清单、可追溯的项目档案；不合格时给出处置记录 |
| 责任人 | 检验员主责，项目／交付人员办理交付，工艺员复核异常与经验反馈 |
| 继续条件 | 检验要求满足后才能标记合格交付；未满足要求的零件不得借用工艺包放行状态作为合格结论 |

检验员按图纸和专项要求确认实际零件，记录不合格项及处置。交付时保留终检结论、实际交付清单及相关版本记录。

经过确认、适用范围明确的现场经验可以进入企业配置或经验库。一次试切结果不应自动成为通用规则。

## 3. 特种加工分支

普通零件不必经过整套电极和线割流程。只有区域确实需要时，才增加相应设计、交接与验收材料。

### 3.1 EDM：先确认为什么不能直接加工

判定应结合区域几何、材料状态、加工时序和实际刀具能力。文档给出的可铣候选刀径区间为：

```text
H / K_max ≤ D ≤ min(0.8W, 2R)
```

其中 W 是刀具路径上的最窄通道宽度，H 是从刀具可下到的最高面到区域底面的深度，R 是要求的最小内圆角，K_max 是有依据的材料对应限值。深槽 `H ≥ 3W` 时，宽度约束从 `0.8W` 收紧为 `0.6W`。

这个区间用于筛选候选刀。区间非空仍要核对刃长、悬伸、刀柄可达性、干涉及机床条件；区间为空则检查替代工艺，不能一律判为拆电极。缺少 K_max 等必要依据时，暂停该判定。

确定采用 EDM 后，增加电极设计、属性、火花图和验收要求。火花位口径必须明确，补偿只实施一次；几何缩小和 CAM 补偿不能重复扣量。工艺文件中的极性按实际机床对照表填写。

### 3.2 WEDM：把交接说明做完整

文档中的“通孔走线切割”有件类和企业策略前提，不能推广到所有零件的所有通孔。例如，模仁通孔与模架规则圆孔在文档中采用不同路线。

选定 WEDM 后，应给出最终轮廓和补偿方向、穿丝孔来源与位置、NC 屏蔽区域、补体清单、线割图及验收要求。

封闭轮廓的穿丝孔设计按文档关系核对：孔在正确的轮廓侧，边距满足补偿要求，每个封闭轮廓都有穿丝入口。打孔前先确认最终轮廓与补偿方向。

交接检查表逐项核对 NC 保留区域、补体数量与对齐、穿丝孔安排、线割图和清单一致性，签字后随件交出。

文档中的 WEDM `R0.15mm`、EDM `R0.03mm` 等值带有本厂配置或示例前提。生产判定使用所选设备经确认的能力，不能直接套用。

## 4. 工艺包要保留什么

内容可以合并到同一份主工艺文件，工序图和检验卡也可按项目组织。减少文件数量时，仍要让下游找到自己需要的信息。

| 内容 | 应包含的信息 |
| --- | --- |
| 工艺路线与工序卡 | 顺序、依赖、对象、设备、参数、余量和工序尺寸；按适用模板给出工序图 |
| 设定与装夹说明 | 工位、坐标系、定位、支承、压紧和刀具清单 |
| 程序与校验材料 | 实际 NC、加工副本、刀路及过切等检查结果 |
| 检验与交接要求 | 检验项、量具、首件和巡检要求、外协技术要求 |
| 追溯记录 | 输入、规则和配置版本，分支依据、变更及未决项 |
| 条件附件 | 适用时的电极设计与火花图、补体清单、线割图、热处理及手工工序说明 |
| 输入图纸 | 已提供的 2D 图纸与技术要求，随包归档 |

不适用项写明不适用。适用内容缺失时，工艺包未完成。

没有程序的热处理、手工精整等工序仍占据工艺路线中的位置，保留执行要求和交接材料。本文不要求生成新的零件 2D 工程图；工序图按模板表达各序要求。

工艺包放行与终检合格分别记录。前者允许现场按计划执行，后者才支持零件合格交付。

## 5. 原文中需要先确认的问题

两份规则库虽标注已同步，详细版仍有旧段落残留。下列问题不宜直接写成自动执行规则。

| 问题 | 建议处理 |
| --- | --- |
| 详细版保留装配、试模、缩水率及已删除 E 组内容，与范围声明冲突 | 整理时采用明确的范围声明，旧段落列为待订正。加工阶段不再换算缩水率 |
| 最终硬度有全必填和条件必填两种写法 | 采用“需要热处理时填写”；其他材料状态要求仍须明确 |
| 渗氮被要求排在 EDM/磨削前，理由却说后续放电会去除渗层 | 暂停自动套用该顺序。由工艺负责人核对处理区域、层深、后续去除量及最终性能要求 |
| 配作尺寸须保留余量，同时又规定不判断配作 | 接收设计已明确给出的配作要求，系统不自行决定哪些尺寸留给配作 |
| “八条一票否决”实际包含可铣、改工艺和禁止 EDM 的情况 | 按具体条件分别分流，不统一实现为“命中就拆电极” |
| 对齐方案提出近似工艺、影子闸和豁免 | 这些是开发与迁移建议，不是生产能力证明，也不能替代放行 |

材料牌号和热处理不能只凭惯例决定。图纸有要求时按已确认要求规划；图纸未说明、牌号又不能唯一确定处理类型时，补齐依据后再继续。

对齐方案中的代码现状基于 2026-10-09 的 CAM-Agent 快照。它可解释当时的缺口，不用于判断当前 Camind 的功能完成度。

## 6. 建议先落地的部分

先解决规则冲突，再补输入与配置校验、基准和装夹表达、标准工序表及交付核对。这样可以复用现有执行链，不必先建设全行业自动分类系统。

普通铣削流程跑通后，再逐项加入 EDM/WEDM 和热处理分支。新增分支必须有明确输入、能力依据、交接材料和放行责任，不能只增加一个工序名称。

装配、试模、改模、缩水率换算和零件 2D 工程图生成不在本建议范围内。现场设备操作仍由具备资质的人员按适用规程执行。
