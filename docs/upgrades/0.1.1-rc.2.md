# dsh 升级记录：0.1.0-rc.7 → 0.1.1-rc.2

日期：2026-08-22。上游 tag `dsh-v0.1.1-rc.2`，commit `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`。

## 上游 breaking changes

1. **`@deepseek-ai/dsh-client-web-react` 整包删除**：slot renderer 并入 `dsh-client-ui-renderer`（`createSlotRenderer`、`ctx.uiRenderer`），作为图内 fetch bundle 加载并自行 `slots.install()`；`dsh-client-web` 的静态表只剩平台单例（react / react-dom / cordis / ui-slots / ui-primitives），`APP_SHELL_ID` 不再导出。
2. **`ClientModuleSystem` 删除 `registerStatic`**：模块系统由 HTML 内联的 `window.__ModuleLoader__` facade 创建（queue → live 两段注册）；boot 图条目新增可选 `external` 字段（动态外部依赖，模块系统按它预取依赖行）。
3. **`dsh-client-ui-attachment` 包根变 Host 存根**：原子组件不再从包根导出；插件半移到 `src/client/`（占 `conversation.input.attachments` / `conversation.message.images`），作为 fetch bundle 提供（自带样式）。
4. **`dsh-client-ui-theme` npm 包不再提供 `styles/` 子路径**：五张全局样式表（含新增 shiki）由官方 ui-theme 客户端插件激活时注入。
5. **官方 Sidebar 新增原生品牌席位** `sidebar.brand.mark` / `sidebar.brand.name`（fallback 为 FishLogo / “DSH Local Build” 文本）；图内新增 `ui-brand-official` 行，在 priority 0 注册这两个席位及 `conversation.hero.brand.mark`（serve 的包已按 official profile 内联，注册真实发生）。
6. **官方前端 fallback 不再回退任意路径**：只在 dist 根与 `/index.html` 提供入口，未匹配路径 404（官方 UI 无客户端路由，不需要深链接）。
7. 杂项：官方包的 peer/dependencies 收窄，katex/shiki/micromark/anser 等不再随 `dsh-client-web` 传递到 npm 消费侧；single 席位同优先级重复注册会 throw，不同优先级共存、最低者渲染。

## 本地适配点

- `scripts/dsh-version.mjs`：`clientPackages` 删 web-react、加 ui-slots（npm 侧不再有传递依赖，需显式固定）。
- `ui-shell/package.json`：4 个客户端包钉 0.1.1-rc.2；vendor 源码的运行时依赖（katex、shiki、@shikijs/langs、anser、clsx、mdast*/micromark* 全家）显式列为 devDeps（上游收窄依赖后 vite 无法解析）。
- `ui-shell/src/web/officialClient.ts`：自建 `__ModuleLoader__` facade（queue 模式），把 layout shim、定制 Sidebar、图外 app-shell 行（`camind-ui-shell/app-shell`）的 factory 预注册进队列，再 `createClientModuleSystem()`；customShell 删掉 `slots.install()`（ui-renderer 图行负责）。
- `ui-shell/src/host/index.ts` + `src/host/types.ts` + `src/shared/protocol.ts`：`/camind/api/client-plugins` 转发图条目的 `external` 字段（否则依赖行不预取、require 失手）。
- `ui-shell/src/web/WorkspaceFileUpload.tsx`：`DropOverlay` 改为相对导入 vendor 源码（`vendor/dsh-client-ui-attachment/src/DropOverlay`）。
- `ui-shell/src/web/main.tsx`：删除 4 个 ui-theme 静态 CSS 引入（官方插件运行时注入）。
- `ui-shell/vite.config.ts`：删 ui-attachment 别名（只剩 ui-primitives 一个）；unwrap 插件导出加 `createClientModuleSystem`；define 加 `process.env.DSH_CLIENT_COMMIT_HASH`（官方 Sidebar 品牌名 fallback 读取）；optimizeDeps 去掉 web-react。
- `ui-shell/vendor/*`：两份快照同步到 rc.2（ui-attachment 新增 `src/client/` 子目录，ui-primitives 新增 `useAnchoredPosition.ts` 等）。
- `ui-sidebar/`：同步 rc.2 源码；**删除本地 `sidebar.brand` 席位**（上游原生 mark/name 替代）；重放两处本地改动——`sidebar.footer.action` owner props 扩展 `{ pathname, navigate }`（含 `declare module` 增广 ui-layout 的 `SidebarOwnerProps`）、账号页脚行（UserChip + settings 固定 `wide: false`，`.footerActions` 纵向排列）。
- `ui-brand/lib/client.js`：迁移到 `sidebar.brand.mark` / `sidebar.brand.name` 两个 single 席位，priority -10 压过图内 ui-brand-official；mascot 尺寸按 owner `size` × 1.25 计算；新增 `/camind` 路径守卫（官方壳保持原生品牌）。
- `page-memory/lib/client.js`：底部菜单项对缺失的 `pathname/navigate` 做防御（官方壳只传 `{ wide }`，官方壳里点击降级为 `location.assign('/camind/pages/memory')`）。
- `ui-shell/src/host/index.ts`：注册 exact `/web` 302 到 `/index.html`（官方壳入口）。

## 验证结果

- `npm run check:dsh-version` 全绿；`cd ui-shell && npm run build` 通过。
- `node scripts/dsh.mjs --profile headless --dump-config` 正常组合。
- 无头浏览器冒烟（零 console 错误）：`/camind/` 新会话页（Camind 品牌区 + 示例卡片、官方 hero 隐藏、工作区行/输入卡）、`/s/:id` 会话详情三栏（Conversation + Workbench「输入/交付物」）、composer 斜杠菜单弹层完整、`/camind/pages/memory` 深链接与底部菜单高亮、折叠 rail 只剩 mascot；官方壳 `/web`（302 到 `/index.html`）保持原生 deepseek 品牌与布局。
