# Camind 第一阶段交付方案

> 状态：交付建议稿。本文整理第一阶段的产品范围与验收目标，不表示相关能力已经全部实现或通过生产验收。整体平台规划见 [Camind 平台设计](camind-platform-design.md)。

## 1. 交付目标

第一阶段向工厂交付一套供工程师使用的 AI 辅助 CAM 编程工作台，完成从接收零件和加工要求，到生成、审核并导出 NC 与加工资料的流程，暂不接管机床。

这一阶段要解决的是工程师日常编程中的重复操作、计算等待、资料分散和现场交接问题。Agent 辅助准备方案和执行编程操作，工程师负责判断、修改和批准，不以无人编程为交付承诺。

是否减少人工投入、缩短交付等待，需要用工厂真实任务验证，不预设未经测量的效率提升比例。

## 2. 工厂拿到什么

工厂使用一个桌面工作台，背后连接云端 NX 计算服务。工程师在工作台处理任务，不需要直接操作云端集群或管理计算调度。

| 工作环节 | 第一阶段提供的能力 |
| --- | --- |
| 接收零件 | 上传模型、图纸和加工要求，集中保存任务资料 |
| 准备方案 | Agent 读件，结合本站点机床、刀具和模板起草加工方案，工程师修改并确认 |
| 编程计算 | 调用云端 NX 生成刀路、完成后处理并输出 NC，展示进度、失败原因和检查结果 |
| 审核修改 | 查看结果、提出修改并重新计算，保留前后版本与批准记录 |
| 交付现场 | 导出 NC、加工设定单和检查报告，交给操作员 |
| 历史复用 | 找回历史任务，复用已确认的资料和方案，修改后重新计算 |

机床程序传输、对刀、装夹、试切和首件检验继续采用工厂现有方式。工作台可以记录结果，但第一阶段不要求自动采集。

## 3. 解决哪些需求

### 减少重复编程操作

对于结构相近的零件，工程师仍需反复读件、组织工序、选择模板、生成程序和整理文件。工作台让 Agent 承担其中可重复的准备与操作，工程师集中处理需要判断和确认的部分。

例如，工厂经常加工结构相近的安装板，可以在历史资料和已确认方案的基础上开展新任务，不必每次从头整理全部内容。实际能节省多少时间，以试点结果为准。

### 保存完整的任务资料和修改过程

一个加工任务可能经历模型修改、工艺调整和多次程序生成。工作台将输入、方案、计算结果和交付版本保存在同一任务下，便于工程师确认：

- NC 对应哪个模型版本；
- 使用了什么机床和后处理配置；
- 哪一版已经批准，哪一版已经被替代。

### 改善编程到操作的交接

操作员除 NC 外，还需要装夹安排、刀具、坐标和注意事项。工作台将这些资料随程序一起导出，减少交接时对编程人员口头解释的依赖。

交付资料用于支持现场操作，不能替代现场检查。

## 4. 一次任务怎样完成

以工厂收到一件铝合金支架的加工任务为例：

1. 工程师上传零件和技术要求，选择已配置的目标机床。
2. Agent 读件，整理待确认问题并起草加工方案。
3. 工程师修改装夹和工序安排，批准本次方案。
4. 云端 NX 生成刀路和 NC，返回结果与检查报告。
5. 工程师审核结果；需要调整时，在原任务中修改并重新计算。
6. 批准后，导出 NC、加工设定单和报告。
7. 操作员按工厂原有方式传程序、装夹和试切，工程师记录首件结果。

这条流程可以作为第一阶段的完整交付，不依赖设备 Agent、Bot 或自主研发系统建成。

## 5. 第一阶段不交付什么

以下能力不作为第一阶段交付的前置条件：

- 设备 Agent、自动传程序和远程启动；
- 手机 Bot APP 和机旁状态终端；
- 生产排产、库存及完整质量管理；
- 公共资源市场；
- Agent 自动修改平台并发布版本。

云端保留支撑工作台必需的身份权限、文件管理、作业管理、NX 接入和运维能力，不要求第一阶段提供完整的平台管理界面。

实施时复用现有 Camind 的上传、机床档案、CAM 执行、交付和查看能力，不另建一套独立系统。复用现有能力不等于相关流程已经满足本阶段的交付要求，仍需完成真实任务验收。

## 6. 如何验收

第一阶段以工厂真实任务为验收依据，不以页面完成或单次生成 NC 成功作为交付标准。

| 验收项 | 判断依据 |
| --- | --- |
| 完整流程 | 工程师能够从接件完成方案、计算、审核和导出，形成现场可审核、可试切的交付资料 |
| 使用收益 | 与原有方式比较，人工投入或交付等待确实减少 |
| 修改与版本 | 修改、重算后，仍能准确识别当前有效版本及其对应输入 |
| 现场交接 | 操作员能够依据交付资料完成交接 |
| 人工接管 | 不适合自动处理的任务能够明确转人工，失败原因不被掩盖 |

验收记录应包含失败和人工接管的任务，不能只统计成功案例。

第一阶段的交付重点是帮助工程师更省事、可追溯地完成 CAM 编程与交付。机床连接留到下一阶段，不作为本阶段可用的条件。
