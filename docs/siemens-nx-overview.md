# 西门子 NX：功能、加工流程与 3D 模型信息

本文整理 NX 在机械加工中的用途、从零件模型到 NC 文件的流程，以及 Camind 通过 NX 工作台读取几何和显示模型的讨论。接口实测记录日期：2026-10-10。

## 1. NX 是什么

西门子 NX 是连接产品设计、工程分析和制造准备的工业软件平台。机械加工业最常用的是 CAD（处理零件模型）和 CAM（编制数控加工程序）。

| 功能领域 | 主要能力 | 加工业用途 |
|---|---|---|
| CAD 设计与建模 | 实体、曲面、装配、工程图、模型修改、尺寸与公差标注 | 查看客户模型、修补几何、设计毛坯和夹具 |
| CAM 数控编程 | 铣削、车削、孔加工、车铣复合、三轴及多轴刀路 | 编制零件加工程序 |
| 加工仿真与验证 | 材料去除、过切与残料检查、碰撞检查、机床运动仿真 | 检查刀路、刀具、夹具与机床干涉 |
| 后处理与车间输出 | 后处理、NC 程序、加工设定单、刀具清单 | 生成指定机床可执行的程序和配套资料 |
| 模具与工装设计 | 分型、模架、电极等专用功能 | 模具及工装制造 |
| 工程分析 | 结构、运动等分析；更完整的仿真体系与 Simcenter 配合 | 评估零件和工装方案 |
| 自动化与数据协同 | 特征识别、加工模板、知识规则、二次开发，与 Teamcenter 等系统集成 | 复用工艺、批量编程、管理版本 |
| 其他制造方案 | 增材制造、检测与机器人加工等相关方案 | 特定设备和工艺场景 |

这些功能并非安装 NX 后全部可用，实际范围取决于版本、许可证、模块和设备配置。

## 2. 典型使用场景

### 普通机加工

板件、支架、箱体、轴类零件。常用平面、型腔、轮廓、槽加工，以及钻孔、扩孔、铰孔、镗孔、攻丝和车削。重点是尺寸质量、编程效率和加工效率。

### 模具加工

型芯、型腔、电极等复杂曲面零件。常见顺序是粗加工、残料加工、半精加工、精加工，重点是曲面质量、余量控制和避免过切。

### 复杂零件加工

叶轮、叶片、薄壁结构件和复杂壳体。往往需要五轴加工，重点是刀轴控制、可达性、碰撞与机床运动检查。

### 批量与系列化零件

零件形状不同，但孔、槽、型腔等结构相似。通过特征识别、模板和规则复用成熟工艺，减少重复编程。

## 3. 从 PRT 模型到 NC 文件

```text
零件模型与加工要求
    ↓
读件与工艺规划
    ↓
定义毛坯、装夹、加工坐标系、机床和刀具
    ↓
创建工序、设置参数、计算刀路
    ↓
仿真与验证
    ↓
匹配目标机床的后处理
    ↓
NC 文件、加工设定单、刀具清单
    ↓
车间准备、首件试切与检验
```

| 阶段 | 主要工作 | 输出 |
|---|---|---|
| 接收与读件 | 导入模型，结合图纸确认材料、公差、表面质量、螺纹和热处理要求 | 加工要求 |
| 工艺规划 | 选择机床、装夹次数、定位基准、粗精加工顺序 | 工艺路线与装夹方案 |
| 加工设置 | 定义成品、毛坯、夹具、坐标系和刀具 | CAM 加工环境 |
| 工序编程 | 选择区域、加工方式、转速、进给、切深、余量和进退刀方式 | 工序与刀路 |
| 仿真验证 | 检查残料、过切、碰撞及适用时的机床运动、行程 | 验证结论与修正后的刀路 |
| 后处理 | 使用匹配具体机床、控制系统和车间要求的后处理器 | NC 程序 |
| 现场加工 | 装夹、装刀、对刀、设置零点、程序检查和首件试切 | 实际零件 |
| 检验反馈 | 检查尺寸与表面质量，必要时调整刀补、参数和工艺 | 合格首件与可复用工艺 |

**刀路**描述刀具如何运动；**NC 文件**是刀路经过后处理后生成的机床程序，两者不是同一个东西。

上传设计好的 `.prt` 可以作为这条流程的起点，但不是直接把模型转换成 NC。还需明确加工要求、毛坯、装夹、坐标系、工序、刀具、参数、目标机床和后处理器。

`.prt` 既可能只有零件几何，也可能包含装配或 CAM 数据，不能只凭扩展名判断。来自 STEP 的模型也不一定保留原始建模特征和设计语义。

在 Camind 中，对应主线是：读件 → 确认工艺 → 绑定机床与刀库 → 生成刀路与验证 → 后处理 → 交付。关键工艺和交付由人工确认。项目实现见 [CAM 加工设计](cam-machining-design.md)。

## 4. NX 能读取哪些 3D 信息

通过 NX Open / UF 接口，可以提取以下信息，但工作台是否对外返回，取决于端点实现。

| 信息 | 内容 |
|---|---|
| 实体与面 | 实体数量、面标识、面类型 |
| 位置与尺寸 | 坐标、包围盒、圆心、半径、轴线方向 |
| 面方向 | 平面法线、曲面指定位置的法线 |
| 拓扑 | 面边界、边、顶点、相邻面 |
| 几何属性 | 面积、体积、质心等 |
| 加工特征 | 孔、槽、型腔等，可通过几何识别获得，不保证模型自带这些语义 |

平面有固定的法线方向；曲面通常没有一个统一法线，需要指定采样点或曲面参数位置。坐标数据也需要明确单位和坐标系，不能默认是加工坐标。

Camind 现有 `cam_survey` 的流程是：解析当前会话上传的 PRT → 上传至 NX 工作台 → 调用 `/cam_survey` → 透传几何事实并生成风险候选。代码见 [survey.js](../tool-cam/lib/tools/survey.js)。

## 5. 新版工作台读件实测

同一零件在工作台更新前后各执行了一次读件，未生成刀路。新版代理报告 `proxy_version: 8-multibase`，读件返回 `schema_version: 4`。

### 基本几何

| 项目 | 结果 |
|---|---|
| 实体 | 1 个 |
| 总面数 | 231 |
| 平面数量 | 77 |
| 圆柱面数量 | 48 |
| 包围尺寸 | 120 × 187 × 30.5 |
| X 范围 | −60～60 |
| Y 范围 | −93.5～93.5 |
| Z 范围 | 30～60.5 |
| CAM 设置 | 未检测到可访问的 CAM 设置 |

返回没有明确标注零件单位，以上数值不自动认定为毫米。包围尺寸不等于已确认的毛坯尺寸。

### 新增的返回信息

| 返回字段 | 本次结果与含义 |
|---|---|
| `planar_faces` | 52 条平面记录，含中心 X/Y、Z 范围、宽高与 `face_tags` |
| `planar_spans` | 去重后的平面高度范围与分类 |
| `cylinder_sample` | 52 条圆柱／圆锥面记录，含直径、轴向长度、位置、Z 范围、方向判断和 `face_tags` |
| `vertical_holes` | 15 条竖直孔记录，含直径、位置、Z 范围、闭合判断和组成面的标识 |
| `freeform_faces` | 26 条自由曲面摘要，含类型、位置、尺寸范围和 `face_tags` |
| 各类 `*_meta` | 数量上限、是否截断、过滤或跳过原因等 |
| `measured` | 本次测量覆盖的类别 |

上述主要列表本次没有因数量上限截断，但它们经过分类、分组或筛选，**不等于全部 231 个面的完整逐面清单**。接口还说明枚举顺序不稳定，调用方不应依赖列表顺序。

竖直孔记录按直径分为 6 条 Φ5、8 条 Φ8、1 条 Φ12。这是识别结果，不代表最终加工孔数；同轴不同直径记录可能属于同一个阶梯孔。接口还跳过了 18 个被判断为部分圆弧的面，不能把所有圆柱面都当成闭合孔。

### 面 ID 已经返回

新版通过 `face_tags` 返回 NX 面的 Tag。例如一个孔关联两个面：

```json
{
  "diameter": 5,
  "cx": -50,
  "cy": -25,
  "zmin": 48.5,
  "zmax": 60,
  "closed": true,
  "face_tags": [69580, 69617]
}
```

单个平面也有对应的 Tag。这些标识可用于关联 NX 中的面，但不能默认在关闭、重新打开或修改模型后仍保持不变；本次未验证跨会话稳定性。不要把 NX Tag 当作长期持久化的业务 ID。

### 本次仍未返回

- 法线向量。
- 完整的边界、边、顶点及相邻关系。
- 显示网格的顶点坐标、三角形索引和顶点法线。

结论仅针对这次 `/cam_survey` 的默认调用，未测试其他几何或网格导出端点。

## 6. 如何在界面显示完整 3D 模型

几何摘要适合显示包围盒、孔位标记等辅助信息，但不足以准确重建完整零件。位置、直径和面法线也不能替代面的边界与完整形状。

建议将分析数据与显示数据分开：

```text
PRT → NX 工作台
        ├─ 几何事实 → 工艺分析与特征标注
        └─ 三角网格 → 浏览器 3D 显示、旋转与缩放
```

网格至少需要顶点坐标和三角形索引，通常还需要顶点法线。可考虑 GLB/glTF 等显示格式；NX 能否直接导出取决于版本和模块，也可以由工作台提取网格后转换。此方案尚未实测。

如果需要点击模型上的面，再查看其几何或选择加工面，还应保留：

**网格三角形 ↔ NX 原始面的标识映射。**

当前刀路查看器显示的是加工轨迹，不是零件实体；现有几何摘要也不能直接作为完整实体预览的数据源。

## 7. 使用边界

- 模型不等于完整加工要求，螺纹、公差、粗糙度和热处理往往仍需查看图纸。
- 刀路计算成功不代表工艺合理，装夹、刀具刚性、材料状态和变形需要工艺判断。
- 后处理需匹配具体机床，不能只按控制系统品牌选取。
- 仿真通过不等于可以直接生产，现场仍需按规程验证和首件检验。
- 本次返回没有明确标注单位和坐标系，也未验证面 Tag 的持久性。
