# 紧凑输入插件

工作台内复用官方 dsh 0.2.0-rc.2 编辑器、发送按钮、引用、附件、快捷键和提交状态，只适配布局。默认空草稿为 360px 宽、约 44px 高；点击或键盘移入输入框后展开至模型视区允许的宽度（最多 760px）。有草稿时保持展开，空草稿离开后收窄。输入支持多行，换行与自动折行均使高度自适应；超过 180px 或视区高度的 30% 后内部滚动。Shift+Enter 换行、Enter 提交沿用官方键位。切到对话后恢复官方完整输入布局，草稿不复制、不重建。

工作台运行时通过 `compactComposer.renderResponse` 渲染状态指示器与当前轮次最新一条工具调用、工具完成/失败或公开回复行；超长省略，完整回复在官方对话读取。结束恢复输入。没有关键信息时隐藏信息条，不显示“正在回复/等待公开输出”等提示。只读取工具名称和真实完成/失败状态，不展示参数、原始结果、上一轮回复或 reasoning。服务未启用时工作台保留原布局。

插件不发送消息、不请求模型、不保存草稿。已有附件保持官方可见、可移除的附件区（可额外占一行），错误通知不隐藏；审批期间恢复官方确认组件。任务列表、模型/权限选择和用量统计在完整对话布局中访问。后台任务的停止入口仍在官方对话，紧凑状态行不提供独立停止按钮。

布局适配使用 `data-composer-card` / `data-input-scroll` 等结构标记，为发送按钮及其布局路径添加私有展示标记，不搬动 DOM、不替换事件。未知结构保留原布局。上游升级必须复核结构、附件、弹出菜单和审批。插件销毁时移除样式及所有私有展示标记。

初始化模板包含 Web/desktop 插件；现有 Web 可通过 `node scripts/dsh.mjs plugin --profile web add ./ui-compact-composer` 安装。桌面 profile 由 Electron 管理，启动前须包含本包的 link 依赖与 bundle。

验证：`node ui-compact-composer/selfcheck.mjs`、`node ui-workbench/selfcheck.mjs`，并使用 `sh ./scripts/desktop.sh` 重启手测草稿跨视图、纯文本提交、等待响应、完成恢复及官方记录。
